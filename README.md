# Облачные технологии

DevOps-лабораторные работы. В качестве примера используется сервис заметок на Python и PostgreSQL.

| Работа | Отчёт |
| --- | --- |
| Лаба 0. Свой сервис | [lab0](lab0/report.md) |
| Лаба 1. Nginx | [lab1](lab1/report.md) |
| Лаба 2. Docker | [lab2](lab2/report.md) |
| Лаба 2 со звёздочкой | [lab2 ⭐](lab2/report-star.md) |
| Лаба 3. CI/CD | [lab3](lab3/report.md) |

Исходники сервиса, конфигурация nginx и Compose находятся в `lab2`. Код и настройки для CI/CD находятся в `lab3` и `.github/workflows`. Порядок локального запуска сервиса описан в [lab2/README.md](lab2/README.md).

Пайплайн проверяет код и собирает образ при изменениях в `lab3` или настройках CI в ветке `main`. Локальный деплой запускается только при ручном выборе или если в настройках репозитория включена переменная `ENABLE_LOCAL_DEPLOY`; для него нужен подключённый self-hosted runner.
